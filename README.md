# 🍽️ conFusion - Restaurant Web Application

**conFusion** is a full-stack restaurant web app built with **React** on the front-end and **Node.js/Express** on the back-end. Users can view restaurant information, browse the menu, and interact with dishes. Authenticated users can comment, rate, and favorite dishes, as well as provide feedback to the restaurant.

---

## 🔧 Tech Stack

- **Frontend:** React, React Router, Redux
- **Backend:** Node.js, Express, MongoDB
- **Authentication:** JSON Web Token (JWT)
- **Other Tools:** Mongoose, RESTful APIs, Bootstrap

---

## ✨ Features

- 🧑‍🍳 View restaurant staff and contact details
- 📋 Browse a dynamic menu with dishes
- ⭐ Authenticated users can:
  - Leave comments and rate dishes
  - Mark dishes as favorites
  - Submit feedback to the restaurant
- 🔒 Secure authentication with JWT
